# ChromaSwarm

12-step multi-agent system that helps non-experts build professional frontend
pages one page at a time. Full spec: `docs/00_HANDOFF_CLAUDE.md` and
`docs/01..04_*.md`. Runtime knowledge base for agents: `knowledge-base/`.

## Layout

- `backend/` — Python 3.11+ orchestrator (`uv`, FastAPI + WebSocket, Pydantic, LangGraph, Anthropic SDK, Playwright).
  - `chromaswarm/state_machine/pipeline_state.py` — B1→B12 state, exit criteria, per-step tool grants.
  - `chromaswarm/state_machine/graph.py` — LangGraph B1–B7, one `interrupt()` per node pass, single router on `pipeline.step`; `PipelineRunner` is the WebSocket-facing API.
  - `chromaswarm/agents/consultant.py` — `ConsultantAgent` interface + `RuleBasedConsultant` (no-LLM baseline).
  - `chromaswarm/agents/llm.py` + `llm_consultant.py` — provider-neutral LLM layer, configured for **OpenRouter** (one key, any model). Three roles in `backend/.env`: `CHROMASWARM_LLM_MODEL` (text: B1–B7 interpretation, B7 feedback, B5 prose; default `qwen/qwen3.8-flash`), `_MODEL_CODE` (B9, default `qwen/qwen3-coder-next`), `_MODEL_VISION` (Clone mode from images; must accept images). The public OpenRouter catalogue is read once so each model gets the right request (reasoning off where allowed, lowest effort where mandatory; JSON mode only where supported, retried without it otherwise). `LLMConsultant` output is validated against closed value sets, prose is rejected unless every number is in `philosophy_facts`, and provider errors fall back to rules. `uv run python -m chromaswarm.agents.llm` validates the model IDs and the live connection. Model unset or placeholder key = rule-based.
  - `chromaswarm/agents/planner.py` — section blueprints, PRODUCT.md / PLAN.md renderers.
  - **Two modes, chosen at B1** (`BuildMode`):
    - *Creative* — real chat (`agents/chat.py`, WS message `{"type":"chat"}`): each message becomes `answer` (passed to the graph like a button, all validation applies), `ask` (Chroma replies from the session's DESIGN.md + standards ch.1–3; the pending question stays) or `revise` (B3 only: change an earlier pillar). Code-level limits in `chat.guard`: never approves B7, choice answers must be offered values, free-text answers keep the user's own words. No LLM → messages go straight through as answers.
    - *Clone* — B1 asks only the link (`clone_source`; a description is optional via the API). Without one, `raw_prompt` = "Dựng lại trang <host>" and the kind of site is guessed at B2 from the reference (`reader.guess_domain`: priced grid → ecommerce, else page-title words). Default = structure clone into a fill-in template; nobody is asked about ownership. "This site is mine" (copy its words and photos) is an opt-in behind a small "Chuyển trang của chính bạn sang Next.js?" link, then confirmed at B3 against the page's own name (declining drops the read content). A description asking for "100% / y hệt" gets one line in the B2 notice (layout and style are copied, the owner's words/photos/brand are not), never a question. B2 runs `clone/reader.py` (Playwright): the page's top-level sections classified onto buildable structures (in its own order), Style DNA → pillars, the reference's own fonts kept (`clone/fonts.py`: loaded from Google Fonts or Fontshare; a font with no Vietnamese glyphs gets a Vietnamese fallback of the same kind right after it in the font stack, and a note; a self-hosted / licensed font that no free host serves falls back to the preset), and — **only when the user confirmed ownership** — per-section text and image URLs (otherwise the JS returns no content). B3/B4 fill themselves from the reference (scope = description); B7 approval still required. Sitemap page slug `clone`; `planner.page_sections()` returns the reference's sections for it. Owned copy is mapped by section kind in `content.owned_clone_copy`. Pages are opened with `open_settled` (wait for `load`, ≤8s for network idle, then scroll through once for lazy / scroll-revealed content). The reader expands tall wrapper blocks and two-column layouts (content + sidebar: the side column's h1 box becomes the hero), keeps navigation, attaches loose headings to the next block in the same column, merges runs of picture-only blocks into one `gallery` section, counts any visual media (img/svg/video/canvas), and recognises feature showcases, testimonials (incl. CSS-drawn quotes / role lines / round-avatar cards), text-card rows, logo strips, list rows (entry + meta: posts with dates, work history) and closing CTAs. Tall `<header>`s (<360px) count as the navbar; fixed-position boxes narrower than half the page (promo widgets, chat bubbles) are skipped. A hero with no visual becomes `hero-text` (email signup when the reference had an input). The page's total content span is measured; under 1100px it is kept as `CloneSource.content_width` → `--container-max` (+ 2 gutters) in DESIGN.md / tokens.css. Sample copy is per domain and allocated page-wide (`content.copy_for`), so sections never repeat each other. **Designer passes (Clone):** B9 builds a wireframe (`app/wireframe.css`: every colour token at its own OKLCH lightness with no chroma, greyscale photos; content files hold `skeleton()` bars, no photos), then B10 runs one graph pass per stage — colour (wireframe.css emptied), content (real `content/*.ts` + `images.ts`) — before integrating (`pipeline.build_passes`). Heal loops skip the wireframe. **Effect check (Clone B2, its own graph pass after the structure read):** `clone/motion_check.py` opens the reference again (visible window with the Motion Inspector cursor unless `CHROMASWARM_HEADED=0`) and operates it: hidden-below-the-fold elements noted, parallax ratio, a slow scroll one viewport at a time timing each reveal frame by frame (start, duration, starting offset/opacity, easing, sibling stagger gap), marquee cycle, header blur, 16 real hovers (lift px, scale, zoom, duration, easing) → `MotionReport` (`clone.motion_report`, Studio card) and per-section `Section.motion` + `Section.motion_params`, which the Motion MCP `build_effect` takes as `distance_px / scale / cycle_s / stagger_ms / blur_px` + duration/easing. `Deps.motion_check` injects a fake; with a fake reader and no fake check the pass is skipped. **Motion (Clone):** `clone/motion.py` holds the probes the effect check runs — below-fold elements hidden before the settle scroll and visible after (scroll-reveal; 3+ siblings = stagger-cards), elements drifting against the scroll (parallax), infinite sideways animations / moving wide tracks (marquee), up to 16 cards/rows/links/buttons hovered for real (hover-lift, hover-zoom, hover-image, underline-link), sticky/blurred header, smooth scroll (Lenis), libraries, and what CSS cannot rebuild (custom cursor, canvas/WebGL → listed as limits). Effects land in `Section.motion` and are built by the Motion MCP server (`build_effect`, CSS only, page-scoped, reduced-motion safe); logo strips get a duplicated marquee track, list rows a decorative hover preview. **Picture/text-led references (Clone B4):** the reader measures `media_share` (visible media area / page area); a structure clone of a portfolio, a page ≥25% pictures or ≥6 picture slots gets a `clone_content` question (`clone/content_slots.py`): a warning that the owner's photos and words are not copied so those parts will look different, the picture slots in page order, and fields for name / headline / intro / project titles / email. Photos arrive as data URLs (downscaled in the Studio), are saved to `workspaces/<session>/uploads/` (image types only, ≤8MB, ≤24) and copied to the app's `public/images/`; `content.user_clone_content` puts them and the words in place of placeholders and samples. Skipping keeps the template samples. **Preview:** `GET /clone/preview?url=` (first-screen screenshot + title, `clone/preview.py`) shown under the link field before reading. The page language follows the reference (`developer/i18n.py`: `<html lang>`, English copy pools + UI strings; other languages build in English). **Components (Clone):** `clone/components.py` reads every page's smallest pieces (heading / text / link / button / image / input / card: box + computed style, never text or URLs) — the reference per reader block at B2 (`clone.components`, `clone.boxes` per section), the rebuild per `[data-swarm-section]` (`data-cs-comp` attributes). `match()` pairs same-kind components by relative position; `section_score()` = 40% components present · 30% placement (IoU) · 20% style · 10% section height; `tune_rules()` writes the reference's font size / weight / tracking / leading / case, radii, button padding (only larger: tap targets) and card shadow/border into `app/match.css` (desktop ≥1200px only, before heal.css; body text never under 16px). **Measured sections (Clone, structure clones):** a section whose reference components are usable (2–48 pieces) and whose structure is not behaviour-bound (`measured.TEMPLATE_ONLY`: header, tabs, accordion, scroller, list rows, logo strip…) gets `Section.layout` + `layout_box` at B2 and is rendered by `developer/measured.py` instead of its template: `clone/layout.py` puts pieces inside the card that holds them (≥85% inside; a frame-filling picture counts), then a recursive XY-cut splits siblings into rows / columns along empty bands; text over a picture becomes a `layer` (pictures behind at their measured place, the rest flows on top); anything else overlapping falls back to reading order. Desktop (≥1200px, inline `<style>` in the component): each node's left offset and width as % of its parent, vertical gaps in px, the reference's top/bottom space and content span, measured type (weights snapped to 400/600, §2.2), radii, card shadow/border; tablet: columns share a row; phone: a stack on the design system's scale. Words: the page's sample copy (or the user's) cut to the length the reference showed in that box, kept in `content/`; pictures: `Art` at the measured aspect ratio; one filled button per section; controls get `data-swarm-id` `<section>-btn|link|input-<n>` (also listed in PLAN.md). Reference measuring (per block, scrolled into view): transparent hover-only elements, slides clipped by their frame (>70%) and decorative aria-hidden media are skipped; a box-less (`display: contents`) wrapper's opacity is ignored; aria-hidden text and big words hidden in the DOM but painted by a canvas over them (WebGL type) count; a heading / link / button whose words sit side by side with a gap, or a huge line with a small caption, is measured piece by piece; text pieces carry their character count and real run width/offset (never the words). Rendering: one-line labels stay one line, centred pieces stay centred, a ≥160px line is the brand wordmark. **Factory (Clone B9):** in `check_section`, after the Design pass, a section cursor splits into crews (chữ / nút & ô nhập / ảnh & thẻ) and one cursor per component (`SwarmOverlay.spawn/crew/merge`), each marking its component ✓ or with its difference; the crews' tuning goes into match.css, the section is measured again, the workers merge back (`PipelineState.factory_log`). **1:1 acceptance (Clone B11, after QA passes, own pass):** `runtime.compare()` opens the reference link in a second window, re-measures both pages, the Master cursor visits every pair in both windows (red flag where they differ), photographs each section of both (`artifacts/compare/<id>-ref|clone.jpg`, served by `GET /sessions/{id}/compare/{file}`, side by side in the Studio), checks the rebuild's effects with the same probes, tunes match.css; if anything was tuned QA runs again, then another comparison (max 2 rounds) → `clone_compare`, `COMPARE.md`. Text and photos are never compared (a structure clone does not copy them), so 100% is reachable only for layout and style. **Fidelity** (`clone/fidelity.py`): both pages read with the same reader + Style DNA, scored 0–100 (structure 35 incl. half credit for the right kind family, height proportions 25, length 10, content width 10, colours + base font 20); B11 in Clone mode writes `FIDELITY.md` and `clone_fidelity`. **Suite** (`clone/suite.py` + `suite.json`, 10 reference sites): `uv run python -m chromaswarm.clone.suite` checks reader output against the baseline (~10s/site); `--build` rebuilds each site rule-based/headless and scores it (`workspaces/_suite/<site>/compare.jpg`, `report.md`); `--update` accepts results as the new baseline. A run fails on a changed section sequence or a fidelity drop > 5 points — run it before committing reader changes.

The user's section order (`planner.sections_from_brief`: announcement-bar, usp-strip, grid-4 with category tabs, picker-recommend…) is used only when they listed ≥3 blocks. A user-given accent keeps its chroma (`palette exact`) and drives the buttons (`brand_actions`).

## Decisions (do not re-litigate)

1. Orchestrator is Python, not TypeScript (doc 04 Part 4 is superseded).
2. Gates are enforced in code: B1–B7 agents get no code-writing tools (`ALLOWED_TOOLS`); Clarity Score = filled pillars / 5; B7 passes only via an explicit user `approve_plan`.
3. B8/B9 run pipelined per section (Dev writes section N while Design measures N−1), not truly simultaneously. B8 = Design installs tokens only; B9 grants both departments' tools because they work pipelined.
4. Design-department changes are written to the workspace token file, never only applied via CSSOM.
5. B11 self-healing loop is capped at `MAX_HEAL_ITERATIONS = 3`, then escalates to the user.
6. Swarm Rebuild is inspiration only; the overlay is written from scratch.
7. Every number in DESIGN.md comes from the engines; an LLM may only write the philosophy prose and pick presets.
8. Unclear answers are re-asked (`interpret()` returns None) — never filled in by the agent. Answers already given in the first prompt are taken (with a verified quote, `agents/brief.py`) and not asked again; nothing is inferred from the product type.
9. Deviations from FRONTEND_STANDARDS.md, chosen to keep APCA / 8pt checks passing: dark-mode text-secondary 78% and text-muted 68% (spec: 72% / 52%); dense section padding 48px (spec: 40–56px, off-grid); mobile type ratio = 1 + 0.6·(r−1). Fonts (presets, i.e. Creative mode; Clone keeps the reference's fonts): Instrument Serif → Playfair Display (editorial-luxury), Outfit/DM Sans → Fraunces/Be Vietnam Pro (warm-organic; serif heading for contrast), because the originals have no Vietnamese subset; `VIETNAMESE_FONTS` + a test guard every preset font.
10. Studio UI itself follows `FRONTEND_STANDARDS.md` (OKLCH tokens in `globals.css`, 8pt spacing, no AI-slop patterns).
11. Anti-cloning (standards §2.4) applies to **Creative mode only**. **Clone mode** (§2.5) may rebuild the reference's whole look identically — layout, colours, typography (its own fonts), spacing — but never its text or images (copyright): structure clone by default, the user's own text/images in `content/`; **Clone 100%** (text, brand, logo, images too) only for the user's own site, opted into behind a small link and confirmed against the page's name at B3. Ownership is never inferred, and without the tick the reader returns no content at all. Clone pages still pass B7 approval, the chapter-2 checks and B11.
